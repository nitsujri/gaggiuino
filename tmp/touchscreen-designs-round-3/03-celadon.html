Functionality and hardware notes
  • All five saved profiles and every stored profile/system field are available through Menu. No profile switcher occupies Home.
  • Preinfusion, soak, transition, pressure/flow profiling, graph preview, dose/stop weight, manual flow, steam, hot water, backflush, descale, tare, screen sleep/brightness, warmup, lighting, Save, and defaults remain accessible.
  • Tank full calibration changes the upper mapping. The installed low-water boundary remains 125 mm: readings above it return 9% and trigger the existing <10% warning.
  • Group flush and backflush require fresh, valid hardware gross weight above the tray threshold. Tare and hiding the scale display do not bypass this. Removing the load or losing the reading stops an active flush. Descale group-head output uses the same guard.
  • The actual controller currently has no no-tray raw baseline configured. The future firmware implementation must remain fail-closed until that baseline is recorded; the 170 g load here is illustrative.
  • Only native-size rectangles, lines, text, bitmap-compatible temperature wheels, and waveform plots are used. Every presented pixel is quantized to RGB565. These are design trials, not compiled HMI/TFT images.
  • Existing page/component commands must be retained or migrated with the controller code before installation. Current controller settings and firmware remain available in the saved checkpoints.
