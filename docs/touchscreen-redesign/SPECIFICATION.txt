1. Architecture and display
Controller-native320x240/RGB565 drawing through existing115200 UART and
FF FF FF command terminators. No replacement HMI/TFT or compiler required.
Stock global variables/fonts and original brewGraph/graphPreview/bM slider
are reused. Controller owns navigation, editable settings and operating mode.
Original visual timers/touch handlers are disabled on overlay pages. Raw0x67
coordinate frames activate targets only after press+release within one target.
Sleep0x68 cannot activate controls; wake0x87 redraws overlays; reset0x88 returns
Home and expires the flush heartbeat. Legacy Home/Tare on native graph remain.
Versioned command extensions to the display are unnecessary: the new protocol
is implemented entirely in the controller using existing native instructions.
Do not change currently installed TFT to a different model/generation.

Native drawing uses fill,xstr,cir,cirs,line; stock font IDs0,1,6. Font6 renders
temperature, ASCII 'C' avoids unsupported degree glyph. Names1..24 printable
ASCII bytes. Native fonts retain stock assets; preview PNGs substitute Arial,
so physical text width/fit and TJC parity remain acceptance items.
TX bounded400commands, each<192bytes; max2commands per control-loop pass,
only when full command+terminator fits available buffer; UART TX256bytes
compile-time checked. RX fixed16bytes, validates packet terminators/timeouts.
No new framebuffer or bitmap ring assets. Native graph timings remain on TFT.
Controller startup explicitly restarts the display for its serial handshake
after SWD-only resets. Display errors are counted and logged on USB. Heartbeat sendme250ms; Home
Flush stops when valid display contact age>=1500ms, including display reset.

5. Tank
ToF enabled, four-sample average; valid range/status, freshness<=1000ms.
Full initial30mm,persisted1..124. Capture fresh full-tank reading or enter;
explicit Save. mm<=full=>100%;full<mm<=125=>round(10+90*(125-mm)/(125-full));

minimum defaults150g,75% of a200g aftermarket tray listing; OEM assembly weight

Sufficient load detects a container, not geometric tray identity.

Home Flush explicit toggle with full pump/open group valve/heaterOFF. Requires
no competing physical switches,good water,fresh display. It ignores tray
weight and can run while automatic startup fill is waiting for calibration. OFF always allowed. Loss stops and clears latch; no autoresume.
Automatic boiler fill/idle pressure release and cleaning cycles use the local
