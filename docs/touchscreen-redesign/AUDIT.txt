Inherited defects corrected during integration:
- Empty/finalized profiler indexing and discarded last phase state.
- Profile serialization vectors had reserve without size; malformed count and
  truncated payload now reject before changing target; wire format unchanged.
- Flow transition hold read used ramp restriction instead of hold restriction.
- Weight formatting overflow/truncation; bounded single snprintf.
- Ofast invalidated NaN temperature detection; useO3+finite check instead.
- Long transition/hold millisecond locals changed to32bits.
- Water readiness OR predicate was always true; now actual low-water block.
- Blocking HX711 reads/timeouts could masquerade as valid zero; new atomic
  cached conversion path and freshness/rail checks; calibration API retained.
- Blocking descale solenoid pulses now interruptible; profile temp never9.
- Backflush pressure gate latched so pressure loss during rest cannot restart.
- Initial fill now requires a calibrated local tray load and restarts its fill
  budget after waiting for tray; manual Home Flush bypasses this restriction.
- Initial fill continued correctly on Indigo notice/menu pages, checks water/
  switches,stops on timeout; does not depend on stock Home page being visible.
- LED enable preference now gates color/effect output when a driver is configured.
- Startup uptime/target serial spam reduced; finite rendering prevents math
  cast errors; fault loops service display and physical switch recovery.

Remaining practical limitations and commissioning requirements
1. Exact installed display/font metrics/touch/sendxy/Nextion or TJC native
   compatibility not physically exercised. No new display image needs compiling.
2. Full UART draw timing,CPU/heap high-water and physical stop latency need
   measurement; native mocks do not reproduce serial or actual peripherals.
3. Tray baseline/minimum must be captured/measured and checked after reboot.
   Guard remains blocked until setup.150g is a provisional estimate,not a measured OEM tray value.
4. Original graphPreview retains its existing linear/conditional-exit limitations;
   it is based on edited settings, not a full engine-equivalent simulator.
5. ToF missing at boot gets one bounded init attempt; repair needs powercycle.
6. EEPROM CRC detects damage but sudden power failure can require full restore.
7. Old full backup restores BENCH firmware; new image is PRODUCTION. First
   powered machine test must verify fill/temperature/actuation,not only styling.
8. Invalid scales can use original predictive espresso behavior; no remote or
   predicted weight authorizes group flushing. Physical rail tests pending.
